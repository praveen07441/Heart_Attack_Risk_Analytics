# Heart Risk Analytics and Prediction Using Machine Learning

## 📌 Project Overview

**Heart Risk Analytics and Prediction Using Machine Learning** is a healthcare data analytics and machine learning project developed using Python.

The project analyzes patient healthcare data to identify patterns and factors associated with heart-attack risk. It combines **Exploratory Data Analysis (EDA), data visualization, feature preprocessing, and machine learning** to transform raw healthcare data into meaningful analytical insights.

A **Logistic Regression** classification model is used to predict the heart-attack risk category based on demographic, lifestyle, clinical, environmental, and socioeconomic factors.

The project follows a complete data analytics workflow:

> **Data → Data Preparation → Exploratory Analysis → Feature Engineering → Machine Learning → Evaluation → Insights**

The project is intended for **educational and analytical purposes** and is not a medical diagnostic system.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze patient healthcare data using Python.
- Understand the distribution of heart-attack risk.
- Identify important demographic and lifestyle factors.
- Analyze clinical factors associated with heart-attack risk.
- Perform data cleaning and preprocessing.
- Handle categorical variables using One-Hot Encoding.
- Perform Exploratory Data Analysis (EDA).
- Create meaningful visualizations.
- Build a machine learning classification model.
- Predict heart-attack risk using Logistic Regression.
- Evaluate the performance of the machine learning model.
- Analyze model coefficients to identify influential features.
- Generate meaningful insights from healthcare data.

---

## 📊 Dataset

The project uses a patient healthcare dataset containing:

- **10,000 patient records**
- **26 columns**
- **23 predictive features**
- **1 target variable**
- **1 patient identifier**
- No missing values in the provided dataset.
